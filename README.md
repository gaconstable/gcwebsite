# George Constable — Personal Website

A minimalist personal website for the things I am working on, listening to,
reading, enjoying, and seeing around the world.

The site uses an editorial white-and-black layout with a tactile, card-based
Library. Each Library card opens through a contained digital ripple interaction.

## Live site

[george-corner-internet.gaconstable.chatgpt.site](https://george-corner-internet.gaconstable.chatgpt.site)

## Run locally

Requires Node.js 22.13 or newer.

```bash
pnpm install
pnpm dev
```

Open [http://localhost:3000](http://localhost:3000).

## Build

```bash
pnpm build
```

Built with React, TypeScript, Tailwind CSS, Vinext, and Cloudflare Workers.
